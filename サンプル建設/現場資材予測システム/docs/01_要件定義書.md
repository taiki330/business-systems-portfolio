# 要件定義書（現場資材予測システム）

作成日: 2026-09-15 ／ ステータス: 開発中（実運用前）

## 1. 背景・目的

サンプル建設では、足場計画図（NDシステム等の足場図面）を元に、現場ごとの資材数量を
事務が見積もっている。この見積もりを図面データから自動化し、資材発注システムの
「予定数量」（`site_product_plans`）に人手を介して取り込めるようにすることが目的。

**最終ゴール**: 足場計画図（あるいは将来的には建築図のみ）を読み込ませると、
品番・規格別の資材数量が書かれた一覧ファイルが出力され、それを資材発注システムの
CSV取り込み画面にアップロードして予定数量へ反映できる状態にすること。

## 2. スコープ

### 2.1 対象にしているもの（今回の開発範囲）

- **足場計画図から数量を抽出する処理**（JWW / DXF / ベクターPDFを読み込み、品番別に集計）
- 抽出した数量と、現場担当者の手拾い実測値との突き合わせ・誤差検証
- 資材発注システム向けのCSV出力形式の設計、および資材発注システム側の取り込み機能との連携確認

### 2.2 対象外・将来検討（今回未着手）

- **建築図のみから足場計画そのものを新規生成すること**（足場計画図がまだ存在しない現場向け）。
  試作は1件行ったが精度は実用に達していない（`02_現状サマリ.md` 5節参照）。
- 出庫実績（実際にどれだけ現場へ出したか）との精度比較。**出庫実績データが未提供のため未着手。**
- 円形・曲線を含むなど、四角形でない複雑形状の建物への本格対応。
- 資材発注システム側の商品コード体系の設計（別チーム・別スケジュールで進行中）。

## 3. 対象システムとの関係

```
[足場計画図]                                    [資材発注システム]
  (JWW / DXF / PDF)                            サンプル建設/資材発注/資材管理実装/web
       │                                         (Next.js + Supabase, 本番稼働に向け開発中)
       ▼
[本プロジェクト]
  図面を読み、品番・規格別に
  数量を自動集計する
       │
       ▼
[CSV出力]  ──────────────────────────────▶  [/plans/import 画面]
  現場ID・品番・名称・数量・区分・根拠            現場を選択 → CSVアップロード
                                               → 商品コード一致で自動選択（一致しない
                                                 行は人が手動で商品を選ぶ）
                                               → 内容確認後「反映」ボタンで
                                                 site_product_plans へ書き込み
```

**重要**: 資材発注システム側の実装（CSV取り込み・自動照合機能）は、
**別の担当者によって実装済み**であることを2026-08-31に確認している。
本プロジェクト側で新たに開発すべきなのは「CSVを正しい形式・正しい精度で出す」部分であり、
取り込み先の機能自体は作る必要がない。実装場所:
`サンプル建設/資材発注/資材管理実装/web/src/app/plans/import/`
`サンプル建設/資材発注/資材管理実装/web/src/components/plans/CsvPlanImportForm.tsx`

## 4. 入力・出力

### 4.1 入力

| 種別 | 必須/任意 | 備考 |
|---|---|---|
| 足場計画図（JWW/DXF/ベクターPDF） | 必須 | スキャン画像（ラスターPDF）は寸法が取得できず使用不可 |
| 建築図（平面図・立面図） | 任意 | あれば元図面との整合確認（高さ検算等）に使う |
| 現場ID | 将来必須 | 資材発注システム側の現場マスタと対応させるためのキー。詳細は05参照 |
| 手拾い実測値（答え合わせ用） | 開発中は必須 | 精度検証のため。本番運用では不要 |

### 4.2 出力（CSV）

資材発注システムの取り込み画面が認識する列名（別名も許容）:

| 列 | 別名として認識される表記 |
|---|---|
| 品番 | 商品コード／資材コード／品番／material_code／code |
| 名称 | 名称／資材名／商品名／name |
| 数量 | 数量／生成数量／補正後数量／予定数量／計上数量 |
| 棟 | 棟／棟名／building（複数棟混在時の絞り込みに使用） |
| 区分 | 区分／classification（「計上」「参考値」で取り込み時の初期チェック状態が変わる） |
| 備考・算出根拠 | 備考／算出根拠／根拠／note（画面表示のみ。DB保存はされない。05参照） |

## 5. 制約・前提

- **元ファイルは一切変更しない。** 加工・分類コピーは生成物側フォルダにのみ作成する。
- 商品コード体系は2026年末稼働に向けて別途検討中で、本ドキュメント作成時点で未確定。
  そのため現時点のCSVはメーカー品番（例: `NHP38N`）をそのまま出力し、
  コード確定後に対応表を挟む設計にしている。
- 出庫実績データは未提供のため、「予測数量 vs 実際の出庫量」の精度検証は実施できていない。
  現状の精度検証はすべて「図面から抽出した数量 vs 現場担当者の手拾い数量」の比較である。

## 6. 成功基準（クライアントからの言明）

2026-08-31時点でのクライアントの発言:「（実際の出庫量ではなく）主要な資材の数量が、
ある程度合っていれば良い」。厳密な全品目一致は求められていない。
現状どの品目がこの基準を満たせているかは `04_精度検証データ.md` を参照。
