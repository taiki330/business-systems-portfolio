# 訂正・取消

![訂正・取消の画面](../images/correction.png)

## この画面でできること

登録を間違えたときに直すための画面です。2つのタブに分かれています。

- **在庫を修正** … 資材の在庫数を、数え直した正しい数に直します。
- **使用/入荷の取消** … 間違えて登録した「使用」や「入荷」を取り消します。取り消すと在庫の数も元に戻ります。

どちらも理由の入力が必要です。記録として残るので、あとから経緯を確認できます。

## 操作手順

### 在庫の数を直す

1. 医院ホームの「🛠 訂正・取消」を押します。
2. 「在庫を修正」タブを選びます（最初から選ばれています）。
3. 「商品」から直したい資材を選びます。選ぶと今の在庫数が表示されます。
4. 「正しい在庫数」に、数え直した数を入れます。
5. 「修正理由」を入力します（**必須**です）。
6. 「この内容で修正する」を押します。
7. 「この商品の在庫を◯に修正します。よろしいですか？」で「OK」を押します。

### 間違えた使用・入荷を取り消す

1. 「使用/入荷の取消」タブを選びます。
2. 「直近の使用登録」または「直近の入荷登録」の一覧から、取り消したい記録を探します。
3. その行の「取消」を押します。
4. 「取消理由を入力してください（必須）」に理由を入れて「OK」を押します。
5. 「✓ 取消しました：◯◯」と表示されれば完了です。

## 各項目の説明

### 「在庫を修正」タブ

| 項目 | 説明 |
| --- | --- |
| 商品 ＊ | 在庫数を直す資材を選びます。 |
| 現在の在庫（参考） | 選んだ資材の、いま登録されている数です。 |
| 正しい在庫数 ＊ | 数え直した正しい数を入れます。0以上の整数です。 |
| 修正理由 ＊必須 | なぜ直すのかを入力します。空欄では登録できません。 |
| この内容で修正する | 入力した数で在庫を上書きします。 |

### 「使用/入荷の取消」タブ

| 項目 | 説明 |
| --- | --- |
| 直近の使用登録 | 最近登録された「使用」の一覧です。 |
| 直近の入荷登録 | 最近登録された「入荷」の一覧です。 |
| 日時 | 登録された日時です。 |
| 品名 | 資材の名前です。 |
| 数量 | 登録された数です。 |
| 取消 | その記録を取り消します。使用の取消は在庫が増え、入荷の取消は在庫が減ります。 |

## 注意事項

- **理由の入力は必須です。** 空欄のままだと「修正理由は必須です。」「取消理由は必須です。」と表示され、登録できません。
- **在庫の修正は「上書き」です。** 差し引きではなく、入力した数がそのまま新しい在庫数になります。
- **入荷を取り消しても、発注の状態は元に戻りません。** 在庫の数は戻りますが、発注の記録は「入荷済み」のままです。発注の状態も直したいときは、システム管理の担当者に連絡してください。
- **取り消した記録は消えません。** 「取り消した」という印が付いて残ります。すでに取り消した記録は一覧に出てきません。
- 一覧に出るのは直近の登録だけです。古い記録は表示されません。
- 同じ修正を続けて送っても二重には登録されません。「この修正は送信済みです。」と表示されます。

## よくある質問

**Q. 「在庫を修正」と「一斉在庫登録」はどう違いますか？**

A. どちらも在庫数を上書きしますが、「在庫を修正」は1件ずつ理由を付けて直すとき、「一斉在庫登録」は棚卸しでまとめて入れ直すときに使います。

**Q. 取り消したい使用登録が一覧にありません。**

A. 表示されるのは直近の登録だけです。古い記録は出てきません。その場合は「在庫を修正」タブで、正しい在庫数に直してください。

**Q. マイナスの在庫を0に戻したいです。**

A. 「在庫を修正」タブで、その資材を選んで「正しい在庫数」に0を入れ、理由を書いて修正してください。

**Q. 「対象の登録はありません。」と表示されます。**

A. 取り消せる使用・入荷の記録がその医院に無い状態です。まだ何も登録されていないか、すでにすべて取り消し済みです。
