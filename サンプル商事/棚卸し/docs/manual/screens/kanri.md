# 管理方式 設定ツール

![管理方式 設定ツールの画面](../images/kanri.png)

## この画面でできること

資材ごとに「どうやって管理するか」を決める画面です。ここでの設定が、在庫一覧の表示や発注候補の出かたを決めます。

管理方式は3つから選びます。

- **数量管理** … 在庫の数を数えて管理します。使うたびに数が減り、発注基準数を下回ると発注候補に出ます。
- **発注トリガー管理** … 数は数えません。QRを読み取った時点で「発注候補」に入ります。細かい消耗品などに向いています。
- **取り扱いなし** … その医院では使わない資材です。一覧の下のほうにまとめられます。

数量管理を選んだ資材には、「発注基準数」（この数以下になったら発注する、という目安）も入力します。

画面を開くと、現在庫一覧にある商品と自動で照合します。管理方式の一覧にだけ存在しない商品が見つかった場合は、既存の設定を変更せず、不足商品だけを自動追加します。

## 操作手順

### 1件ずつ設定する

1. 医院ホームの「⚙️ 管理方式を設定」を押します。
2. 画面下部に「一覧漏れ ◯件を自動追加しました」と表示された場合は、追加件数を確認します。
3. 「すべて（◯件）」「発注トリガー管理（◯件）」「数量管理（◯件）」から、表示したいタブを押します。
4. 「カテゴリ」や「品名・発注先で絞り込み」で、設定したい資材を探します。
5. その行の「管理方式」から選びます。
6. 「数量管理」を選んだ場合は、右の「発注基準数」に数を入れます。
7. 右下の「保存する」を押します。
8. 確認の表示で内容を確かめて「OK」を押します。

### まとめて設定する

1. 設定したい資材の行の左のチェックボックスにチェックを入れます（「表示中を全選択」で表示中すべてを選べます）。
2. 上の「まとめて設定 →」から管理方式を選びます。
3. 必要なら「発注基準数」に数を入れます。
4. 「選択項目に適用」を押します。
5. 右下の「保存する」を押します。

## 各項目の説明

| 項目 | 説明 |
| --- | --- |
| カテゴリ | 資材の種類でしぼり込みます。 |
| 品名・発注先で絞り込み | 入れた文字を含む資材だけを表示します。 |
| すべて（◯件） | 管理方式に関係なく、すべての資材を表示します。かっこ内に全件数が表示されます。 |
| 発注トリガー管理（◯件） | 現在「発注トリガー管理」になっている資材だけを表示します。かっこ内に該当件数が表示されます。 |
| 数量管理（◯件） | 現在「数量管理」になっている資材だけを表示します。かっこ内に該当件数が表示されます。 |
| 表示中を全選択 | 表示されている行すべてにチェックを入れます。 |
| ◯件選択中 | いまチェックが入っている件数です。 |
| まとめて設定 → | チェックした資材に一括で設定する管理方式を選びます。「数量管理」「発注トリガー管理」「取り扱いなし」「未設定に戻す」から選べます。 |
| 発注基準数（上の欄） | まとめて設定するときの発注基準数です。空欄でもかまいません。 |
| 選択項目に適用 | 選んだ内容を、チェックした行に反映します（この時点ではまだ保存されていません）。 |
| カテゴリ・発注先・品名・現在庫（表の列） | 資材の情報です。 |
| 管理方式（表の列） | その資材の管理のしかたを選びます。 |
| 発注基準数（表の列） | この数量以下になったら発注する、という目安です。**数量管理のときだけ**入力できます。 |
| ◯件を読み込みました（医院名） | 表示している資材の件数です。 |
| 一覧漏れ ◯件を自動追加しました | 現在庫一覧にはあるものの、この画面になかった商品を不足分だけ追加した件数です。 |
| 保存する | 変更した内容をまとめて保存します。 |

## 注意事項

- **「選択項目に適用」を押しただけでは保存されません。** 必ず最後に「保存する」を押してください。
- **発注基準数は0以上の数を入れてください。** それ以外だと「発注基準数は0以上の数値で入力してください。」と表示されます。
- **数量管理にしたのに発注基準数が空欄だと、発注候補に上がりません。** 保存前の確認画面に「⚠ 数量管理で発注基準数が未入力：◯件（未入力のままだと発注候補に上がりません）」と表示されるので、確認してください。
- **「取り扱いなし」にしても資材は消えません。** 一覧の最下部に残るので、あとから戻せます。
- チェックを入れずに「選択項目に適用」を押すと「先に対象の資材にチェックを入れてください。」と表示されます。
- 医院ホームを経由せずに開くと「医院が指定されていません。医院ホームから開いてください。」と表示されます。
- 自動追加は不足商品だけを対象にします。すでに一覧にある商品の管理方式・発注基準数は変更しません。
- タブの件数は、画面上で管理方式を変更した時点で更新されます。保存前の変更も件数に含まれます。

## よくある質問

**Q. 「数量管理」と「発注トリガー管理」はどちらを選べばよいですか？**

A. 数を把握したい資材（在庫切れを防ぎたいもの、金額が大きいもの）は「数量管理」、数は数えずに「無くなりそうになったら発注する」で足りる資材は「発注トリガー管理」を選んでください。

**Q. 発注基準数はいくつにすればよいですか？**

A. 「これ以下になったら発注したい」数を入れます。判定には未入荷の数も足して計算されるので、発注済みで届いていない分がある間は候補に上がりません。

**Q. 「取り扱いなし」にした資材を元に戻したいです。**

A. 一覧の最下部にありますので、その行の管理方式を選び直して「保存する」を押してください。

**Q. 保存したのに在庫一覧の表示が変わりません。**

A. 在庫一覧の画面で「再読み込み」を押してください。

**Q. 現在庫一覧にある商品が、この画面にありません。**

A. この画面を開き直してください。現在庫一覧と自動照合し、不足商品だけを追加します。追加された場合は画面下部に「一覧漏れ ◯件を自動追加しました」と表示されます。

**Q. 発注基準数の欄が入力できません。**

A. その行の管理方式が「数量管理」以外になっています。発注基準数は数量管理のときだけ使う項目です。
