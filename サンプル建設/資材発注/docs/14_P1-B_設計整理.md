## 1. 背景と目的

P0 は **倉庫在庫（center）** と **出庫依頼** まで実装済み。`shipped` で center は減るが、**貸出在庫（現場に出ている自社所有分）** はシステム上持てない（`docs/10` §2-1）。

P1-B の目的は **棚卸で数が合う状態の土台**を作ること（[16](./16_P1-B_決定事項.md) D-20260620-01）。手段として:

1. **貸出在庫**を現場別に保持する
2. **返却・現場間移動・調整**を台帳（`stock_ledger` 拡張）に残す
3. 倉庫在庫＋貸出在庫の合計が説明可能になる

### 1-1. P1-B / P1-B+ / P1-C

| 区分 | 内容 |
|------|------|
| **P1-B（中核）** | 自社所有の貸出在庫・返却・現場間移動・履歴 |
| **P1-B+** | 棚卸・差異確定・センター調整後数量（`U-2` / `U-6` 確定後） |
| **P1-C** | リース会社・リース品・Excel 取込・現完滅失（`docs/05` §5-1） |

リースの**業務ニーズ**は確定（B-REQ-08〜10）だが、**実装は P1-C**。P1-B では `ownership` 列など拡張ポイントの有無のみゲート 1 で判断する。

### 2-1. 設計原則

1. P0 のテーブル・RPC は **拡張または新 RPC 追加**（破壊的変更を避ける）

3. 在庫更新は **RPC で原子的に**（`apply_stock_movement` / `ship_stock_request` パターン）
4. 用語は `docs/10` に従う（本文では **貸出在庫**を正とし、「現場在庫」は画面ラベルとしてのみ使用可）

## 5. データ設計の方向性（ゲート 1 前ドラフト）

> migration・RPC 詳細は **U-1〜U-4 確定後**に本節を具体化し、[17](./17_P1-B_実装計画.md) ゲート 1 の成果物とする。

### 5-1. `stock_items` 拡張（方針）

- `storage_kind`: `'center' | 'site'`
- `site_id`: `storage_kind='site'` のとき必須
- `ownership`: `'owned'`（P1-B）/ `'leased'`（P1-C・ゲート 1 で列追加要否を判断）
- 既存 `location` は移行期 **併存**（P0 無回帰）

### 5-2. `stock_ledger` 拡張（方針）

| movement_type（候補） | 意味 | Phase |
|------------------------|------|-------|
| `in` / `out` | center 向け（P0・維持） | — |
| `ship_to_site` | center↓ 現場↑（shipped 連動） | P1-B-1 |
| `return_to_center` | 現場↓ center↑ | P1-B-2 |
| `transfer_site` | 現場 A↓ 現場 B↑ | P1-B-3 |
| `adjustment` | 棚卸差異 | P1-B-6 |

`reference_type` / `reference_id`（例: `stock_request`）で **依頼とのトレーサビリティ**を確保する（ゲート 1 で必須化）。

### 5-3. RPC（方針）

| RPC | Phase |
|-----|-------|
| `ship_stock_request` 拡張 or v2 並走 | P1-B-1 |
| `return_from_site` | P1-B-2 |
| `transfer_between_sites` | P1-B-3 |
| `apply_stock_adjustment` | P1-B-6 |

いずれも internal ガード + 1 トランザクション。

### 5-4. P0 テーブルとの関係（概要）

```text
stock_requests（ステータス維持）
  └─ shipped ──► ship_stock_request（拡張）
                    ├─ center OUT（既存）
                    └─ site IN（新規・site_id へ）

return / transfer ──► 専用 RPC ──► stock_ledger + stock_items
```

## 8. リスクサマリー

| 前提の変更 | 影響度 |
|------------|:------:|
| shipped ≠ 貸出在庫増のタイミング | **高** |
| quantity 上書き vs `shipped_quantity` 分離 | **高** |
| snapshot 正 vs ledger 正 | **高** |
| 返却漏れ＝現完滅失に変更 | **高** |
| リースを `stock_items` 同一行に同居 | **高** |
| 現場間移動に承認 WF 必須 | 中 |
| センター専用ダッシュボード必須 | 中 |
