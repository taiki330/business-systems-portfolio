# 給与売上シート 作成手順

毎月10日〆・28〜29日振込。振込額が確定したあとの作業です。

---

## フォルダの中身

```
給与売上シート\
│
├ 実行.bat            ← ふだん使うのはこれだけ
│
├ 入力\               ← キングオブタイムのCSVをここへ
├ 出力\               ← 結果がここに出る
│
├ 控えを作る.bat        ときどき実行（バックアップ）
├ 環境チェック.bat      調子が悪いときに実行
├ セットアップ.bat      最初の1回だけ
├ 入力シート_原本.xlsx   毎月ここから複製されます。触らないでください
├ 手順書.md             このファイル
└ tool\
   └ 従業員マスタ.csv    入職された方があったときだけ触ります
```

---

## 毎月の作業

### 1. キングオブタイムからCSVをダウンロードする

「勤怠支給控除一覧表」を、次の分すべて出力します。

| | ファイル | |
|---|---|---|
| ① | 10日〆勤怠支給控除一覧表 | 毎月 |
| ② | 固定残業10日〆勤怠支給控除一覧表 | 毎月 |
| ③ | ココロハズム勤怠支給控除一覧表 | 毎月 |
| ④ | 賞与支給控除一覧表 | 賞与のある月のみ |

**ファイル名は変えないでください。** 先頭8桁の支給日で月を判別しています。

### 2. 「入力」フォルダに入れる

前月分が残っていたら消してから入れてください。
（残っていても動きますが、揃っているかを確かめやすくするためです）

### 3. 「実行.bat」をダブルクリックする

黒い画面に集計結果が出ます。**内容を読んでから**キーを押して閉じてください。
終わると「出力」フォルダが自動で開きます。

### 4. メールで送る

開いた「出力」フォルダの中から、

**`<支給日>_共有用.xlsx`**

を、いつものメール画面にドラッグして添付し、送信してください。

**このファイルには個人の給与額は入っていません。** 医院別の合計だけです。

---

## 出力されるもの

| ファイル | 中身 | 扱い |
|---|---|---|
| `..._給与売上（入力シート）.xlsx` | 従来のシートに数字が入ったもの | **全員の給与額が入っています。院内には出さないでください** |
| `..._共有用.xlsx` | 医院別の合計だけ | **これをメールに添付します** |
| `..._確認事項.txt` | 画面に出た内容の控え | 記録用 |

入力シートの数式と書式はそのまま残っています。開けば従来どおり合計が計算されます。

---

## 画面に「確認が必要です」と出たら

処理は続きますが、**内容を確認してから出力ファイルをお使いください。**

### 重複 — ○○（123）が給与で複数のファイルにあります

同じ方が2つのファイルに入っています。**そのままだと二重計上になります。**
移籍などで意図的な場合を除き、キングオブタイム側をご確認ください。

### CSVが不足しています —「○○」のファイルがありません

ダウンロードし忘れです。追加して実行し直してください。

---

## 処理が止まったら

**ファイルは1つも作られません。** 画面の指示どおりに直してから、もう一度実行してください。

### マスタにない社員番号があります

新しく入職された方です。`tool\従業員マスタ.csv` に1行足してください。

```
社員番号,氏名,所属医院,区分,入力シート行,按分ルール,状態,備考
123,山田花子,サンプル歯科A,DH,,,対象,
```

- **所属医院** … サンプル歯科B／サンプル歯科A／サンプル歯科C／サンプル商事／訪問 のいずれか
- **入力シート行** … 入力シートの何行目に置くか。空欄でも集計には入ります
- **按分ルール** … 通常は空欄
- **状態** … `対象`。計上しない方は `除外:理由`

### 所属医院に、扱いの決まっていない名前があります

書き間違いです。上の5つのいずれかに直してください。
医院そのものが増えた場合は、集計の作り替えが必要です。ベクサムへご連絡ください。

### 金額が合いません

マスタの内容に不整合があります。画面の金額差を添えて、ベクサムへご連絡ください。

### ファイルを上書きできませんでした

先月の出力をExcelで開いたままです。閉じてから実行し直してください。

## 手を動かさなくてよいこと

| | |
|---|---|
| **退職** | CSVに載らなくなれば自動で外れます |
| **育休・復帰** | 同上。復帰すれば自動で戻ります |
| **改姓** | 社員番号で照合しているので影響しません |

**退職された方を、先回りでマスタから消さないでください。**
その月まで在籍しておられた分の集計が狂います。放っておけば自動で外れます。

## ときどきやること

**`控えを作る.bat`** をダブルクリックすると、やり直しのきかない設定を
日付つきのZIPにまとめます。

USBメモリやクラウドなど、**このパソコン以外の場所**にも置いておいてください。
パソコンを買い替えたときは、これを戻すだけで再開できます。
