# Shiflun 法務相談資料（兵庫労働局・弁護士向け）

本ディレクトリは、Shiflun の本格営業・契約開始前に、兵庫労働局および弁護士へ相談するための資料一式です。

作成基準日: 2026-08-13（リポジトリ `shiflun/shiftLink` の現状コード・ドキュメントおよびこれまでの検討内容に基づく）

## 免責・取り扱い上の注意

- **本資料はいずれも法的な結論を示すものではありません。** 「〜に該当する」「問題ない」といった断定は行わず、判断が必要な事項はすべて「要確認」として明記しています。
- 本資料中の「現在の実装」は 2026-08-13 時点のリポジトリのコード・DB スキーマに基づく事実です。「今後の構想」は要件定義書（`要件定義書_業種特化型・シフト連動型マッチングアプリ.pdf`）に記載された将来計画であり、**未実装**です。両者は明確に分けて記載しています。
- 本資料の作成にあたり、コード・DB・UI の変更は一切行っていません。

## 使い方（想定シナリオ）

1. **兵庫労働局へ相談する場合**: [01](01_service-overview.md) → [02](02_money-flow.md) → [03](03_questions-hyogo-labor-bureau.md) の順に見せる。01・02 だけで「Shiflun が何をするサービスで、お金がどう流れる想定か」を数分で把握できる構成にしてあります。
2. **弁護士へ相談する場合**: [01](01_service-overview.md) → [02](02_money-flow.md) → [04](04_questions-lawyer.md) の順に見せる。
3. **相談結果の反映**: 労働局・弁護士から得た回答は [05_open-issues.md](05_open-issues.md) の「現在案」「確定すると影響する機能」列を更新し、社内の実装判断に反映する運用を想定しています（本相談時点ではまだ反映されていません）。
