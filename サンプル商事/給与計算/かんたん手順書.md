# 給与の集計 かんたん手順書

この道具は、キングオブタイムで確定した給与データを、医院ごとにまとめてExcelの表を作ります。銀行への振込は、この道具では行いません。

最初の設定が済んだパソコンで使う手順です。

## 毎月の作業

### 1．今月の給与データを用意する

キングオブタイムから、今月の次のデータを「CSV」という形式で保存します。CSVは、この道具が読み込むためのファイルです。

- 10日〆勤怠支給控除一覧表
- 固定残業10日〆勤怠支給控除一覧表
- ココロハズム勤怠支給控除一覧表
- 賞与支給控除一覧表（賞与のある月は、該当する分もすべて）

保存したファイルの名前は変えないでください。名前の最初にある8桁の数字が、今回の支給日になっているか確認します。

※ キングオブタイムでどのボタンを押すかは、このフォルダの資料だけでは確認できません。初回に担当者と一緒に確認してください。

### 2．給与計算の「入力」に入れる

1. この給与計算のフォルダを開きます。
2. 「入力」というフォルダを開きます。
3. 前月のCSVがあれば、保管先へ移して、今月分と混ざらないようにします。
4. 保存した今月のCSVを入れます。

**ファイルのコピーが分からない場合**

1. 保存したファイルを1回クリックします。
2. キーボードの「Ctrl」を押しながら「C」を押します。
3. 給与計算の「入力」フォルダを開きます。
4. 「Ctrl」を押しながら「V」を押します。
5. 必要なファイルすべてについて繰り返します。

通常の給与分3種類が揃っていることを確認してください。「参考データ」は毎月の作業には使いません。

### 3．「実行」を開く

1. 給与計算のフォルダに戻ります。
2. 「実行.bat」を、マウスの左ボタンで素早く2回押します。これが「ダブルクリック」です。
3. 黒い画面が出ます。計算が終わるまで待ちます。

パソコンの設定によって、名前が「実行」とだけ表示される場合もあります。

### 4．結果を確認する

黒い画面の次の内容を確認します。

- 「支給日」が今回の支給日になっている。
- 読み込んだファイルが、今月の必要な分すべてになっている。
- 「確認が必要な事項はありません」と出ている。
- 「金額の突合」のところに、合計が「一致しました」と出ている。

**「確認が必要です」「中止」などが出たら、その内容を確認するまで送らないでください。** 分からない場合は、黒い画面をスマートフォンで撮って、担当者へ相談してください。

確認できたら、画面の案内に従って「Enter」キーを押します。「出力」というフォルダが自動で開きます。開かなければ、給与計算のフォルダから「出力」を開きます。

### 5．今月の「共有用」をメールに付ける

1. 「出力」の中で、今回の支給日が付いた「共有用.xlsx」を探します。
2. 開いて、支給日と医院別の金額を確認し、Excelを閉じます。
3. いつものメール画面を開きます。
4. 宛先・件名・本文を入れます。
5. クリップのマークや「添付」を押します。
6. 給与計算の「出力」フォルダを開き、今回の「共有用.xlsx」を選びます。
7. メールに付いたファイル名と宛先をもう一度確認して、送信します。

例：支給日が2026年8月29日なら、「20260829_共有用.xlsx」を選びます。この日付は例です。毎月、今回の支給日を確認してください。

| ファイル名の最後 | 内容と使い方 |
|---|---|
| 共有用.xlsx | 医院別の集計表。医院へのメールに付けるのはこちらです。個人別の給与額は入りません。 |
| 給与売上（入力シート）.xlsx | 個人別の給与額が入った表。医院への共有メールには付けません。 |
| 確認事項.txt | 黒い画面に出た内容の記録。困ったときに確認します。 |

## 毎月とは別に、確認すること

- **入職した方がいるとき：** 「従業員登録.xlsx」の5行目以降に、社員番号・氏名・所属医院・職種を追加して保存します。個人別の金額は出力の「新入職者」タブに表示されます。事務・技工士は担当者に確認してください。
- **医院を移った方がいるとき：** 登録されている所属医院を直す必要があります。自動では分かりません。集計前に担当者へ伝えてください。
- **退職・育休・復帰・改姓：** 通常は登録を消す必要はありません。給与データに載っている方をもとに集計します。
- **ハノワの分：** この道具では自動入力されません。請求書を見て、作成された「給与売上（入力シート）」のハノワ欄に、これまでどおり入力してください。共有用に反映する作業が必要な場合は、担当者に確認してください。

## うまくいかないとき

| 表示・状況 | すること |
|---|---|
| CSVが不足しています | 必要な今月のCSVを「入力」に追加して、もう一度「実行」を開きます。 |
| ファイルを上書きできません | 出力のExcelを閉じてから、もう一度「実行」を開きます。 |
| マスタにない社員番号があります | 新しい方の登録について、担当者へ相談します。 |
| 重複、金額が合わない、その他の確認事項 | 画面を撮り、担当者へ相談します。確認前には送信しません。 |
| 動かない・黒い画面がすぐ消える | 「環境チェック.bat」をダブルクリックし、出た画面を担当者へ伝えます。 |

## ときどき、控えを残す

「控えを作る.bat」をダブルクリックすると、設定の控えができます。できた控えは、担当者と決めた、このパソコン以外の保管場所にも保存してください。

「入力シート_原本.xlsx」と「tool」フォルダの中身は、普段の操作では変更しません。

## 説明する方へ

最初は「今月のデータを入れる → 実行を開く → 結果を確認する → 共有用をメールに付ける」の順に、一緒に操作してください。次に、ご本人に同じ操作をしてもらい、迷ったところだけ説明すると覚えやすくなります。

最初の説明で使える言い方：

「毎月の給与データをこの『入力』に入れて、『実行』を2回クリックすると、医院ごとの表ができます。画面の結果を確認してから、『共有用』という名前の表を、いつものメールに付けて送ります。」
