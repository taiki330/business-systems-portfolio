# 4. 弁護士への質問事項

[← 目次に戻る](README.md)

## 前提

本書は、兵庫労働局への相談（[03_questions-hyogo-labor-bureau.md](03_questions-hyogo-labor-bureau.md)）だけでは判断しにくい、契約・民事責任・個人情報・決済まわりの論点を整理したものです。サービス概要・お金の流れは [01_service-overview.md](01_service-overview.md)・[02_money-flow.md](02_money-flow.md) を参照。

## 1. 利用規約

- 現行の利用規約案（`利用規約（ワーカー・店舗共通）V3.md`、全18条）について、[03](03_questions-hyogo-labor-bureau.md) の労働局への確認結果（職業紹介／募集情報等提供いずれの位置づけになるか）を踏まえたうえで、法的に有効・整合的な内容になっているかレビューをお願いしたい。
- 特に第5条（スカウトおよび契約成立）・第10条（免責事項）は、Shiflunが契約当事者にならないという整理を前提にしているが、この整理自体が有効に機能する規約構成になっているか。
- 第18条（準拠法・東京地方裁判所の専属的合意管轄）について、店舗・ワーカーが全国に分散しうる事業特性上、実務上の問題（管轄合意の有効性、消費者契約法上の制約等）がないか。
- 店舗が個人事業主の場合と法人の場合とで、規約上の取扱いを分ける必要があるか。

## 2. 個別の労働契約（店舗・ワーカー間）

- 現行案は「スカウト承諾＝契約成立」という設計だが、この契約が雇用契約か業務委託契約かをShiflun側で決め打ちすべきか、それとも店舗ごとの選択制にすべきか。それぞれの場合に規約・アプリ仕様へ与える影響。
- Shiflun がアプリ上に保持する「スカウト承諾ログ」（日時・条件・承諾操作の記録）は、店舗・ワーカー間の契約成立の証跡としてどの程度の証拠力を持つか。契約書面化・電子署名等の追加対応が必要か。
- 未成年ワーカー（規約第13条、満16歳以上・高校生を除く。親権者同意を前提）について、労働契約法・未成年者の労働契約に関する労働基準法上の規制（第58条〜第59条等）との関係で、同意取得の方法（アプリ上でどう取得・記録すべきか）に問題がないか。

## 3. 責任分界

- 免責条項（第10条：店舗・ワーカー間のトラブル一般に無関係、マッチング等の成果を保証しない／第14条4項：キャンセル・無断欠勤による損害に無関係／第16条2項：勤務中の事故等に無関係）について、Shiflunの事業実態（スカウトの個別勧誘、条件提示、成果報酬の徴収）に照らして、免責が有効に認められる範囲はどこまでか。
- 第14条3項（店舗都合の直前キャンセルに所定の手数料）について、この手数料の法的性質（違約金・損害賠償の予定・その他）と、消費者契約法・民法上の上限規制等との関係。
- eKYCによる引き抜き防止措置（第6条：直接雇用へ移行したワーカーの同一店舗への再登録を技術的にブロック）について、職業安定法（労働者の直接採用の自由の制限に関する規制）や独占禁止法（優越的地位の濫用等）の観点から問題がないか。

## 4. キャンセル・事故

- ワーカーの無断欠勤（第14条2項）に対する措置（警告・機能制限・アカウント停止）の設計は適法か。過度な制裁とみなされるリスクはないか。
- 勤務中の事故・怪我についてShiflunが一切の責任を負わないとする整理（第16条2項）は、実際の訴訟・クレーム対応の場面でどこまで防御になるか。第三者賠償責任保険等、Shiflun側で加入を検討すべき保険はあるか。

## 5. 個人情報

- eKYC導入時に取得する本人確認情報（氏名・生年月日・身分証画像等のPII）の取扱いについて、個人情報保護法上の要配慮個人情報への該当性、取得・保管・委託（外部eKYCサービスとの連携）における留意点。
- 店長認証コメント等、ワーカーに対する第三者（店長）評価情報の取扱い（本人開示請求への対応、訂正・削除request対応等）。
- 現時点でプライバシーポリシーが未整備であることを踏まえ、最低限どのタイミングまでに整備すべきか。

## 6. 決済

- [02_money-flow.md](02_money-flow.md) の3案（無仲介／決済プラットフォーム介在／立替払い）について、資金決済法（資金移動業・為替取引該当性）の観点からそれぞれのリスクを評価してほしい。特に案A（無仲介）が本当に「為替取引」を行っていないと言えるか（Shiflunが「いくら払うか」を指示する行為の位置づけを含む）。
- 「収納代行」の位置づけと、近年の資金決済法改正の動向（個人間送金目的の収納代行に対する規制強化等）を踏まえ、本サービスの構造（店舗→ワーカーという事業者から個人への支払い）がどの規制の射程に入るか。
- PAY.JP Platform / Stripe Connect等の第三者決済基盤を利用する場合（案B）、Shiflun・店舗・ワーカー・決済基盤運営者の四者間の契約関係をどう整理し、利用規約にどう反映すべきか。
