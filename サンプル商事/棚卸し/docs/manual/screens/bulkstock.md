# 一斉在庫登録（棚卸し）

![一斉在庫登録の画面](../images/bulkstock.png)

## この画面でできること

棚卸しの日に使う画面です。実際に数えた在庫の数を入力して、システムの在庫数を**上書き**します。

入力した行だけが更新されます。**空欄のままの行は変更されません。** そのため、何人かで手分けして数え、それぞれのスマホから同時に保存しても問題ありません。

一覧の「入力状況」で、その商品が本日すでに登録されたか確認できます。標準カメラから1件ずつ登録した商品も対象です。

資材のQRコードを標準カメラで撮影し、その写真から商品を特定して入力することもできます。

## 操作手順

### 数を入力して保存する

1. 棚卸しの日に配られる専用のURLを開きます。
2. 画面上部に自分の医院の記号が表示されていることを確認します。
3. 「入力状況」で「✓ 本日入力済み」または「未入力」を確認します。
4. 他の人が登録中の場合は入力状況が自動更新されます。すぐ確認したいときは「🔄 入力状況を更新」を押します。
5. 探しやすいように「カテゴリ」や「品名で絞り込み」を使って表示をしぼります。
6. 数えた資材の行の「数えた実数」に、実際の数を入力します。**在庫が無い資材は「0」を入力**してください（空欄にすると変更されません）。
7. 入力が終わったら、右下の「入力分を保存」を押します。
8. 「入力した◯品目の在庫を確定（上書き）します。よろしいですか？」で「OK」を押します。
9. 「◯品目を確定しました。最新を再読み込みします…」と表示されれば完了です。

### QRコードを撮影して入力する

1. 「📷 QRを撮影」を押します。
2. 標準カメラで、資材に貼ってあるQRコード全体を正面から撮影します。
3. 撮影した写真を使用します。
4. 読み取った資材の名前と入力欄が表示されます。「－」「＋」または直接入力で数を入れます。
5. 「この数で記入」を押すと、一覧のその資材の欄に記入されます。
6. 次の商品は、もう一度「📷 QRを撮影」を押します。
7. 最後に「入力分を保存」を押します。

## 各項目の説明

| 項目 | 説明 |
| --- | --- |
| カテゴリ | 資材の種類でしぼり込みます。 |
| 品名で絞り込み | 入れた文字を含む品名だけを表示します。 |
| 🔄 入力状況を更新 | 他の人が登録した結果をすぐ読み直します。自分がまだ保存していない入力内容は残ります。入力状況は画面へ戻ったときにも自動更新されます。 |
| 📷 QRを撮影 | 標準カメラでQRコードを撮影し、その写真から商品を特定します。端末内の画像を選ぶこともできます。 |
| 入力状況 | 本日登録済みの商品は「✓ 本日入力済み」と登録時刻、未登録の商品は「未入力」と表示します。 |
| カテゴリ（表の列） | 資材の種類です。 |
| 品名 | 資材の名前です。 |
| 現在庫（参考） | いまシステムに登録されている数です。参考として表示しているだけで、ここは変更されません。 |
| 数えた実数 | 実際に数えた数を入れる欄です。0以上の整数を入れてください。 |
| ◯品目（数量管理） | この医院で数量管理をしている資材の件数です。 |
| 入力分を保存 | 入力した行だけを確定（上書き）します。 |

### QR写真を読み取った後の表示

| 項目 | 説明 |
| --- | --- |
| － ／ ＋ | 数を1つずつ減らす・増やすボタンです。 |
| 実数（入力欄） | 数を直接入力する欄です。 |
| この数で記入 | 入力した数を、一覧のその資材の欄へ記入します。 |

## 注意事項

- **保存すると、その資材の在庫数は入力した数で上書きされます。** 元の数は残りません。数え間違いに注意してください。
- **在庫が0のものは、空欄ではなく「0」を入力してください。** 空欄のままだと「数えていない」と判断され、数が変わりません。
- **この画面に出るのは「数量管理」の資材だけです。** 在庫の数を数えない資材（発注トリガー管理）は表示されません。
- **マイナスの数は入力できません。** 「在庫数は0以上の数値で入力してください。」と表示されます。
- 同じ内容を続けて保存しても二重には登録されません。「この保存は送信済みです（二重送信を防止）。」と表示されます。
- 「本日入力済み」は本日の在庫確定履歴を基準に表示します。日付が変わると「未入力」に戻ります。
- 他のスマホで登録した結果は、画面へ戻ったときに自動更新されます。画面を開いたまますぐ確認したい場合は「🔄 入力状況を更新」を押してください。
- 保存に失敗したときは「保存できませんでした：◯◯」「もう一度「保存」を押してください。」と表示されます。入力した内容は残っているので、もう一度押してください。
- QRを撮影する方式は、ブラウザ内でリアルタイムカメラを起動しません。端末の標準カメラまたは画像選択画面を使います。
- 「QRを読み取れませんでした。QR全体を明るく、正面から大きく撮影してください。」と表示された場合は、QR全体が入るように撮影し直してください。

## よくある質問

**Q. 何人かで分担して入力しても大丈夫ですか？**

A. 大丈夫です。入力した行だけが保存されるので、それぞれの担当分を入力して、それぞれのスマホから保存してください。

**Q. 他の人が登録した商品を確認できますか？**

A. 「🔄 入力状況を更新」を押してください。本日登録済みの商品に「✓ 本日入力済み」と登録時刻が表示されます。

**Q. QRを読んだら「この一覧にない資材です（◯◯）。発注トリガー管理の資材、または他院の資材の可能性があります。」と出ました。**

A. その資材はこの一覧の対象外です。在庫の数を数えない資材（発注トリガー管理）か、別の医院の資材のどちらかです。棚卸しの対象外なので、そのまま次に進んでください。

**Q. 「このシステムのQRではありません。」と出ます。**

A. このシステムで発行したQR以外を読み取っています。「QRコード生成」画面で印刷したQRを使ってください。

**Q. 途中で画面を閉じてしまいました。**

A. 保存を押す前の入力内容は残りません。もう一度入力してください。こまめに「入力分を保存」を押すことをおすすめします。

**Q. 間違えた数で保存してしまいました。**

A. もう一度この画面で正しい数を入力して保存すれば上書きできます。1件だけ直したいときは「訂正・取消」画面でも修正できます。
