# QRコード生成（印刷用）

![QRコード生成（印刷用）の画面](../images/qrprint.png)

## この画面でできること

資材に貼る札の「QR面」と「写真面」を画面に並べて表示し、そのまま印刷する画面です。印刷したQRをスマホのカメラで写すと使用登録ができます。

品名・発注先・商品IDで検索できます。「写真面」では、商品写真と発注基準を登録できます。

医院ホームから開いた場合は、**その医院で使う資材のQRだけ**が表示されます。

印刷が終わった資材は「印刷済み」にしておくと、次回から一覧に出てこなくなります。まだ印刷していないものだけを表示できるので、貼り忘れを防げます。

## 操作手順

1. 医院ホームの「🏷 QRコード発行」を押します。
2. 「カテゴリ」または「品名・発注先で検索」で、印刷する資材を絞り込みます。
3. 「印刷面」で「QR面」を選びます。
4. 「印刷する」を押してQR面を印刷します。
5. 「印刷面」で「写真面」を選びます。
6. 「写真未登録」の資材は、その場で撮るなら「📷 撮影」、すでに撮ってある写真を使うなら「🖼 写真を選ぶ」を押します。
7. 撮影するか、端末に入っている写真を選びます。保存後、写真面が再読み込みされます。
8. 発注基準を入力します。数量管理は0以上の整数、発注トリガー管理は「半分になったら発注」などの条件を60文字以内で入力します。
9. 「発注基準を保存」を押します。
10. 「印刷する」を押して写真面を印刷します。
11. 印刷が終わったら、カードの「✓ 印刷済みにする」を押します。
12. 表示中の分をすべて印刷した場合は、「表示中をすべて印刷済みにする」でまとめて印を付けます。

## 各項目の説明

| 項目 | 説明 |
| --- | --- |
| カテゴリ | 表示する資材の種類をしぼり込みます。 |
| 品名・発注先で検索 | 品名・発注先・商品IDの一部を入力して、表示する資材を絞り込みます。 |
| 印刷面 | 「QR面」または「写真面」を選びます。 |
| 再読み込み | 最新の一覧を取り直します。 |
| 印刷する | ブラウザの印刷画面を開きます。 |
| 印刷済みも表示する | チェックを入れると、すでに印刷済みにした資材も一覧に表示します。 |
| 表示中をすべて印刷済みにする | 表示されている資材をまとめて印刷済みにします。 |
| ◯件表示中（医院名で使う資材のみ） | 表示している枚数と、絞り込みの条件です。 |
| QRの画像 | 資材ごとのQRコードです。 |
| 商品写真／写真未登録 | 「写真面」で表示されます。登録済みの写真が無い場合は「写真未登録」と表示されます。 |
| 📷 撮影 | その場でカメラを起動して商品写真を撮り、保存します。 |
| 🖼 写真を選ぶ | スマホやパソコンに入っている写真から選んで保存します。 |
| 品名 | その札がどの資材のものかを表します。QR面・写真面の両方に印刷されます。 |
| 発注基準 | 写真面だけに印刷されます。数量管理では発注候補にする基準の数、発注トリガー管理では発注する条件です。登録が無い場合は「未設定」と表示されます。 |
| 発注基準の入力欄 | 数量管理は0以上の整数を入力します。発注トリガー管理は「半分になったら発注」などの条件を60文字以内で入力します。 |
| 発注基準を保存 | 入力した基準をこの医院の商品へ保存します。入力欄とボタンは印刷されません。 |
| ✓ 印刷済みにする | その資材を印刷済みにします。次回から既定では表示されなくなります。 |
| 印刷済みを解除 | 印刷済みの印を外します。 |

## 注意事項

- **印刷済みにしても、QRコードそのものは変わりません。** 印刷の管理のための印なので、貼り直したいときは「印刷済みも表示する」にチェックを入れれば、また印刷できます。
- **写真を登録すると、同じ商品の以前の写真は差し替えられます。** 写真を選ぶ前に商品名を確認してください。
- **写真の差し替えも同じボタンです。** 「📷 撮影」「🖼 写真を選ぶ」のどちらからでも上書きできます。
- **QR面に印刷されるのはQRコードと商品名です。** 写真面には商品写真・商品名・発注基準が印刷されます。画面上の入力欄とボタンは印刷されません。
- 数量管理の発注基準に小数や負の数を入力すると「数量管理の発注基準は0以上の整数で入力してください。」と表示されます。
- 発注トリガー管理の条件が60文字を超えると「発注する条件は60文字以内で入力してください。」と表示されます。
- 管理方式が未設定の場合は「管理方式が未設定の商品です。先に管理方式を設定してください。」と表示され、発注基準を保存できません。
- 写真データは保存前に自動で縮小されます。それでも大きい場合は「写真が大きすぎます。端末のカメラ設定で画像サイズを小さくしてお試しください。」と表示されます。
- **「表示中をすべて印刷済みにする」は、表示されている全件が対象です。** 押す前に、本当に全部印刷したかを確認してください。「表示中の◯件をすべて印刷済みにします。よろしいですか？」という確認が出ます。
- **印刷済みの管理は医院ごとです。** 同じ資材でも、医院が違えば別々に管理されます。
- 印刷は資材の枚数によっては大量になります。カテゴリで絞ってから印刷することをおすすめします。
- 「対象の商品がありません。 先に「②商品マスタ・医院別在庫を生成」を実行してください。」と表示された場合、現場では対応できません。システム管理の担当者に連絡してください。

## よくある質問

**Q. QRを印刷したら、どこに貼ればよいですか？**

A. 資材の箱や、保管している棚など、使うときにすぐ写せる場所に貼ってください。運用のルールは医院で決めてください。

**Q. 一覧に出てこない資材があります。**

A. すでに「印刷済み」になっている可能性があります。「印刷済みも表示する」にチェックを入れて確認してください。それでも出ない場合は、その資材がこの医院の在庫に登録されていません。

**Q. QRが読み取れません。**

A. 印刷が小さすぎたり、かすれていると読み取れないことがあります。もう一度印刷し直してください。

**Q. 写真面に「写真未登録」と表示されます。**

A. 「📷 撮影」で商品を撮るか、「🖼 写真を選ぶ」で端末内の写真から選んでください。保存後に写真面が再読み込みされます。

**Q. 発注基準が「未設定」と表示されます。**

A. この医院の商品に発注基準が登録されていません。写真面に切り替え、基準を入力して「発注基準を保存」を押してください。

**Q. 新しく追加した資材のQRはどうすればよいですか？**

A. この画面を開くと自動的に一覧に追加されています。「再読み込み」を押してから印刷してください。
