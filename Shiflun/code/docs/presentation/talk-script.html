SLIDE 2 課題 — 飲食業界が直面する3つの壁 約2分30秒
キーメッセージ
聴衆に「これは自分ごとだ」と感じてもらう。数字より現場のリアルな声で伝える

まず、飲食業界が直面している課題からお話しします。飲食店でアルバイトをした経験、または経営の経験がある方はいらっしゃいますか？

実は飲食業界には、今も解決されていない大きな課題が3つあります。

1つ目は、シフト管理の非効率です。多くの店では今もLINEや紙でシフトを管理しています。希望を集めて、集計して、表を作る。この作業に毎週2〜3時間かかっているという声は珍しくありません。

2つ目は、急な欠員への対応です。前日のドタキャン、当日の体調不良。こういうとき店長ができるのは、連絡先リストを端から電話することだけです。それでも誰も来なければ、自分が入るか、営業を縮小するしかない。

3つ目は、スポットワークの信頼性問題です。初めて来るバイトが本当に来るのか、スキルがあるのかわからない。この不安が、スポット採用に踏み切れない大きな理由になっています。

それぞれは小さく見えますが、毎日積み重なることで、店長の時間と精神力を大きく奪っています。

SLIDE 3 解決策 — シフト希望に連動したマッチング 約2分
キーメッセージ
「今働ける人」に絞ったことで、スピードと信頼性が同時に実現する

シフルンはこの問題を、アプローチを変えることで解決します。

まずバイトがスマホからカレンダーで希望日と時間を登録します。次に店長が確認して、自分の店に入れるか判断します。「この日は人が足りている」という場合は、その空き時間を他の店舗に開放することができます。

人手が足りない別の店舗がその情報を見てスカウトを送り、バイトが承諾すればマッチング成立です。

重要なのは、このマッチングが「その日確実に働ける人」だけに絞られているということです。一般的な求人サービスは応募から採用まで数日から数週間かかります。シフルンは最短当日のマッチングが可能です。

補足（余裕があれば）：店長がシフトを開放する判断をするだけでいい。新しいオペレーションを増やすのではなく、今やっていることの延長線上に乗っている設計にこだわりました。
SLIDE 4 機能 — 両サイドに最適化された機能 約2分
キーメッセージ
バイトは「使いやすい」、店舗は「管理が楽になる」の両立を具体的に見せる

実際に何ができるのか、バイトと店舗それぞれの視点でご説明します。

バイト側では、カレンダーから複数の日をまとめて選んで一括でシフト希望を提出できます。今日のシフトが採用済みであれば、アプリから出勤打刻もできます。スカウトが届いたら条件を確認してワンタップで承諾。店長から認証バッジをもらうことで、実績を次のスカウトにつなげられます。

店舗側では、月・週カレンダーでスタッフ全員のシフトを一元管理できます。参加申請が来たらアプリ内で承認、人手が足りない日は条件検索でバイトを探してスカウト送信まで完結します。

今まで電話やLINEで行っていたやり取りが、すべてシフルン上で完結します。

SLIDE 5 差別化 — 他社にないシフルンだけの強み 約2分
キーメッセージ
「なぜ既存サービスじゃダメなのか」に答える。技術的対策まで言及して信頼感を出す

「スポットバイトのサービスは他にもあるのでは？」という疑問を持たれるかもしれません。シフルンには、他のサービスにはない3つの強みがあります。

1つ目は、シフト希望と連動したマッチングです。一般的なサービスはバイトが仕事を探して応募する形ですが、シフルンは逆です。バイトが空き時間を登録しておくと、店舗からスカウトが来る。しかも「その日働ける人」だけが対象なので、採用ミスマッチが起きにくい。

2つ目は、店長認証による実績の可視化です。どこの店で何年働いたかが、店長の認証という形で信頼できる情報として見えます。履歴書より正確な「現場の評価」です。

3つ目は、eKYCによる引き抜き防止です。シフルンを通じて知り合った後に直接雇用に移行した場合、同じ本人確認情報でのシステム再登録を自動でブロックします。プラットフォームの公平性を技術で守っています。

SLIDE 6 ビジネスモデル — バイトは無料、店舗は成果で払う 約1分30秒
キーメッセージ
シンプルで納得感のある構造であることを示す。「採用できなければ払わなくていい」が刺さる

収益モデルはシンプルです。

バイト側は完全無料です。登録からシフト提出、スカウト受信まですべて無料。バイトの数がサービスの価値の源泉なので、使いやすさを最優先にしています。

店舗側は成果報酬型です。マッチングが成立したときだけ費用が発生します。採用できなかったのにコストがかかる、という無駄が一切ありません。加えてシフト管理機能は月額プランもご用意しています。

小規模な個人店から複数店舗のチェーンまで、スタッフ数に応じたスケール設計になっています。
