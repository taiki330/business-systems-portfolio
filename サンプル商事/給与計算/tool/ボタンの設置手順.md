# 送信ボタンの設置（初回だけ・3分）

`送信ブック.xlsm` には送信ボタンが置いてありますが、**中身のプログラムはまだ空**です。
Excelのセキュリティ設定により、プログラムを外から自動で書き込むことができないためです。
（これは正しい設定なので、緩めません）

一度だけ、下の手順で貼り付けてください。**以後ずっと使えます。**

---

## 手順

### 1. `送信ブック.xlsm` を開く

上部に黄色い帯で「セキュリティの警告 マクロが無効にされました」と出たら
**「コンテンツの有効化」**を押してください。初回だけ聞かれます。

### 2. `Alt` + `F11` を押す

VBAの編集画面が開きます。

### 3. 左側の「VBAProject (送信ブック.xlsm)」を右クリック

**挿入 → 標準モジュール**

右側に白い入力欄が出ます。

### 4. 下のコードを、まるごとコピーして貼り付ける

```vb
Sub SendSharedSheet()
    Dim sh As Object
    Set sh = CreateObject("WScript.Shell")
    sh.Run """" & ThisWorkbook.Path & "\送信.bat""", 1, False
End Sub
```

### 5. `Alt` + `Q` で編集画面を閉じ、`Ctrl` + `S` で保存

「マクロ有効ブックとして保存しますか」と聞かれたら **はい**。

---

## 確認

シート上の **▶ 送信** ボタンを押してください。
黒い画面が開き、送信結果が表示されれば成功です。

まだメールアドレスを設定していない場合は、こう出ます。これで正常です。

```
[中止] 送信先のメールアドレスが未設定です。
```

---

## メールアドレスの設定

`tool\送信設定.csv` をメモ帳（またはExcel）で開き、**宛先**の行にアドレスを入れて保存します。

```
項目,値
宛先,tanaka@example.com
CC,
件名,【給与売上】{年}年{月}月{日}日 支給分 集計
```

- `CC` は空でも構いません
- 件名と本文の `{年}` `{月}` `{日}` は、送信時に支給日へ置き換わります
- 本文を変えたいときも、このファイルを編集してください

---

## 送信されるもの

**`出力` フォルダにある最新の `共有用.xlsx` が1つ添付されます。**

- 全医院の合計が1シートに入っています
- 個人の給与額は入っていません
- マクロは入っていません（送信ブックとは別のファイルです）

## 送信されない場合

その月に**確認事項が残っていると、送信は止まります。**

```
[中止] この月には未解決の確認事項が残っています。
  重複 — 従業員D俊一（425）が給与で複数のファイルにあります: ココロハズム と 固定残業
```

内容を確認し、必要なら `実行.bat` をやり直してから送信してください。
確認のうえ問題ないと判断された場合は、`出力\<支給日>_確認事項.txt` の
「■ 確認が必要です」の行を消すと送信できるようになります。
