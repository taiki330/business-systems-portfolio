# 履歴の保管・削除

![履歴の保管・削除の画面](../images/historyadmin.png)

## この画面でできること

システムは操作のたびに記録（履歴）を書き足していきます。そのままにしておくと履歴が増え続け、数年後にシステムが重くなります。

この画面では、**年に1回**、次の2段階で古い記録を片づけます。

1. 基準日より前の記録を、Googleドライブに新しいスプレッドシートとして**書き出して保管する**
2. 書き出せたことを確認したうえで、**元の履歴から消す**

1をしていないと2は実行できません。いきなり消えることはありません。

## 操作手順

### 1. 対象の件数を確認する

1. 「在庫管理ホーム（理事長・事務）」から「履歴の保管・削除」を押します。
2. 「基準日（この日より前を対象にします）」に日付を入れます。はじめは1年前の日付が入っています。
3. 「件数を数え直す」を押すと、履歴ごとの「対象件数」が出ます。

### 2. 書き出して保管する

1. 「書き出して保管する」を押します。
2. 「◯◯より前の履歴 ◯件を書き出して保管します。（この操作では元の履歴は消えません）よろしいですか？」で「OK」を押します。
3. 「書き出しています…件数が多いと1〜2分かかります。」と出るので待ちます。
4. 終わると「書き出しました（◯件）。」とアーカイブIDが表示されます。
5. **「保管したファイルを開く」を押して、中身が入っていることを必ず確認します。**

### 3. 元の履歴から削除する

1. 「削除するアーカイブ」で、いま書き出したものを選びます。
2. 「元の履歴から削除する」を押します。
3. 「この操作は元に戻せません。保管ファイルの中身は確認しましたか？」で「OK」を押します。
4. 「最終確認です。◯◯の対象期間の履歴を削除します。よろしいですか？」でもう一度「OK」を押します。
5. 「削除しました（合計 ◯件）。」と表示されたら終わりです。

## 各項目の説明

### いま溜まっている履歴

| 項目 | 説明 |
| --- | --- |
| 基準日（この日より前を対象にします） | この日より前の記録が、保管と削除の対象になります。 |
| 件数を数え直す | 基準日を変えたあと、対象件数を数えなおします。 |
| 履歴 | 対象になる記録の種類です。 |
| 全件数 | いま入っている記録の件数です。 |
| 期間 | いちばん古い記録と新しい記録の日付です。 |
| 対象件数 | 基準日より前にある記録の件数です。 |
| まだ記録がありません | その履歴にはまだ1件も記録が無いという意味です。 |

対象になる履歴は次の5つです。

| 履歴 | 中身 |
| --- | --- |
| 使用履歴（QR読取での使用登録） | QRを読んで資材を使った記録です。 |
| 在庫確定履歴（棚卸しでの一斉登録） | 棚卸しで数えた実数を登録した記録です。 |
| 入荷履歴 | 届いた資材を入荷登録した記録です。 |
| 資材移動ログ（医院間の貸し借り） | 医院どうしで資材をやりとりした記録です。 |
| 在庫修正履歴 | 在庫の数を手で直した記録です。 |

### 1 書き出して保管する

| 項目 | 説明 |
| --- | --- |
| 書き出して保管する | 基準日より前の記録を、新しいスプレッドシートとして書き出します。元の履歴は消えません。 |
| 保管したファイルを開く | 書き出したスプレッドシートを別のタブで開きます。 |
| アーカイブID | 書き出しごとに付く番号です。削除するときにこの番号を選びます。 |

### 2 元の履歴から削除する

| 項目 | 説明 |
| --- | --- |
| 削除するアーカイブ | 書き出し済みで、まだ削除していないものだけが並びます。 |
| 元の履歴から削除する | 選んだアーカイブの対象期間の記録を、元のシートから消します。 |

### これまでの保管・削除の記録

| 項目 | 説明 |
| --- | --- |
| ID | アーカイブIDです。 |
| 書き出し日時 | 書き出しを実行した日時です。 |
| 対象 | どの日より前を対象にしたかです。 |
| 件数 | 書き出した記録の件数です。 |
| 保管ファイル | 「開く」を押すと保管したスプレッドシートが開きます。 |
| 削除 | 削除済みなら日時と件数が、まだなら「未削除」と表示されます。 |

## 注意事項

- **削除は元に戻せません。** 消す前に、必ず保管ファイルを開いて中身が入っていることを確認してください。保管ファイルを消してしまうと、削除した履歴は二度と戻せません。
- **書き出しをしていないと削除できません。** 「削除できるアーカイブがありません。先に上の『書き出して保管する』を実行してください。」と表示されます。
- **「発注管理」「発注候補」「QR印刷済み」は消えません。** いま発注中の資材や印刷済みのQRという「今の状態」を持っているため、この作業では触りません。
- **対象が0件だと書き出しできません。** 「対象の記録が0件のため実行できません。」と表示されます。
- **基準日に未来の日付は指定できません。** 指定すると「基準日に未来の日付は指定できません」というエラーが出ます。
- **同じアーカイブを2回削除することはできません。** 「このアーカイブ（◯◯）の削除は既に実行済みです。」と表示されます。
- **保管ファイルを消したり移動したりすると削除できなくなります。** 「保管ファイルが見つかりません」と表示され、元の履歴はそのまま残ります。
- 書き出しは件数が多いと1〜2分かかります。画面を閉じずにお待ちください。

## よくある質問

**Q. 年に1回とありますが、いつやればよいですか？**

A. 「資材の稼働率」で1年間の見直しをしたあとに行うのがおすすめです。稼働率は使用履歴から計算しているため、先に削除してしまうと1年分のグラフが見られなくなります。

**Q. 削除したあと、あとから記録を見たくなったらどうしますか？**

A. 書き出したスプレッドシートを開いてください。「棚卸しシステム_履歴アーカイブ」フォルダに入っています。

**Q. 対象件数が0件のままです。**

A. 基準日より前の記録がまだ無いという意味です。運用を始めたばかりの時期はこの状態が普通です。そのまま何もしなくて構いません。

**Q. 削除しないとどうなりますか？**

A. すぐに壊れることはありませんが、履歴が増えるほどQRを読んだときの反応が少しずつ遅くなります。年1回この作業をしていれば、その心配はありません。
