# 資材の稼働率

![資材の稼働率の画面](../images/usagerate.png)

## この画面でできること

「この資材は最近ほとんど動いていないのに、在庫を持ちすぎではないか」を見つける画面です。年に1回の在庫の見直しに使います。

**稼働率**は、直近1年（12ヶ月）のうち、その資材が使われた月の割合です。

- 12ヶ月すべてで使われた → 100%
- 12ヶ月中5ヶ月で使われた → 42%
- 1年間まったく使われなかった → 0%

使った「数量」ではなく「動いた月」で見るので、少しずつ毎月使う資材もきちんと「動いている」と出ます。

一覧は稼働率の低い順に並ぶので、上から見ていけばそのまま見直しの候補になります。各行の「グラフ」ボタンを押すと、その資材の月ごとの使用数量が折れ線で表示されます。

## 操作手順

1. 「在庫管理ホーム（理事長・事務）」から「資材の稼働率」を押します。
2. 「使用履歴を集計中…」と表示されるので、そのまま待ちます。
3. 稼働率の低い資材から順に一覧が表示されます。
4. 医院ごとに見たいときは「医院」を選び直します。選ぶと自動で集計しなおします。
5. 特定の資材を探すときは「品名・発注先で絞り込み」に文字を入れます。
6. 気になる資材の行の右にある「グラフ」ボタンを押すと、月ごとの使用数量が表示されます。
7. グラフを閉じるときは、右上の「×」を押すか、グラフの外側を押すか、キーボードの「Esc」を押します。
8. 元の画面に戻るときは、いちばん下の「← 理事長・事務ホームへ戻る」を押します。

## 各項目の説明

### 画面の上の部分

| 項目 | 説明 |
| --- | --- |
| 医院 | 「全医院（合計）」または医院ひとつを選びます。選ぶと自動で集計しなおします。 |
| 品名・発注先で絞り込み | 入れた文字を含む資材だけを表示します。集計はしなおしません。 |
| 再集計 | いまの条件で、もう一度集計しなおします。 |

### 4つの数字

| 項目 | 説明 |
| --- | --- |
| 対象の資材 | 集計した資材の品目数です。 |
| 1年間まったく使われていない | 稼働率が0%だった資材の品目数です。 |
| その在庫金額（税抜） | 上の「まったく使われていない」資材が、いくらぶん在庫として残っているかの合計です。 |
| 集計した使用履歴 | 集計に使った使用履歴の件数です。 |

### 資材一覧

| 項目 | 説明 |
| --- | --- |
| 品名 | 資材の名前です。下に小さくカテゴリと発注先が出ます。 |
| 稼働率 | 12ヶ月のうち使われた月の割合です。棒の色は、0%が赤、50%未満がオレンジ、それ以上が緑です。 |
| 年間使用数 | 直近1年で使われた数量の合計です。 |
| 最終使用 | 最後に使われた月です。1年間使われていない場合は「使用なし」と出ます。 |
| 現在庫 | いまの在庫数です。 |
| 在庫金額 | 税抜価格 × 現在庫 で計算した金額です。単価が登録されていない資材は「—」になります。 |
| グラフ | その資材の月ごとの使用数量を折れ線で表示します。 |

### グラフの画面

| 項目 | 説明 |
| --- | --- |
| 稼働率 ◯%（12ヶ月中 ◯ヶ月で使用） | その資材が使われた月数です。 |
| 年間使用数／月平均 | 直近1年の合計と、1ヶ月あたりの平均です。 |
| ◯ヶ月動いていません | 直近で何ヶ月続けて使われていないかです。 |
| 折れ線グラフ | 横が月、縦が使用数量です。点にマウスを合わせるとその月の数量が出ます。 |
| × | グラフを閉じます。 |

## 注意事項

- **使用履歴からしか計算できません。** QRを読んで使用登録をした記録が元データです。運用を始めたばかりで履歴が少ないうちは、ほとんどの資材が0%と表示されます。
- **期間は直近1年で固定です。** 変更はできません。
- **在庫数を数えない資材（発注トリガー管理）は現在庫・在庫金額が「—」になります。** その資材は在庫数を持たないためです。
- **この画面では在庫の登録や修正はできません。** 見るだけの画面です。
- **年1回の「履歴の保管・削除」で使用履歴を消すと、その分のグラフは見られなくなります。** 見直しを先に済ませてから削除してください。
- 「集計に失敗しました：◯◯」と表示されたときは、ページを再読み込みしてください。それでも直らない場合はシステム管理の担当者に連絡してください。

## よくある質問

**Q. 全部の資材が0%と表示されます。**

A. 使用履歴がまだ溜まっていない状態です。「集計した使用履歴」が0件になっていないか確認してください。QRを読んでの使用登録が始まると、そこから数字が入りはじめます。

**Q. 稼働率が低い資材は、すぐ在庫を減らしてよいですか？**

A. この画面は候補を見つけるためのものです。年に数回しか使わないが必要、という資材もあります。各医院に確認したうえで判断してください。

**Q. 「在庫金額」が「—」になっている資材があります。**

A. 商品マスタに税抜価格が登録されていないか、その資材が在庫数を持たない（発注トリガー管理）かのどちらかです。単価は「商品マスタ管理」画面で登録できます。

**Q. グラフが出ません。**

A. 「グラフ」ボタンを押すと画面に重なって表示されます。閉じたあともう一度見たいときは、同じボタンをもう一度押してください。
