# 総資産・全医院サマリ

![全医院サマリの画面](../images/director.png)

## この画面でできること

すべての医院の在庫状況を1画面で見わたす画面です。医院ごとの資産額（在庫の評価額）、品目数、在庫不足の件数などが並びます。

各医院のカードを押すと、その医院の在庫管理ホームに移動できます。

## 操作手順

1. 「在庫管理ホーム（理事長・事務）」を開き、「総資産・全医院サマリ」を押します。
2. 「全医院を集計中…（少し時間がかかります）」と表示されるので、そのまま待ちます。
3. 全医院の合計と、医院ごとのカードが表示されます。
4. 気になる医院があれば、そのカード（「ホームへ →」）を押すと、その医院の画面に移動できます。
5. 元の画面に戻るときは、いちばん下の「← 理事長・事務ホームへ戻る」を押します。

## 各項目の説明

### 上の帯（全医院の合計）

| 項目 | 説明 |
| --- | --- |
| 全医院 資産評価額 合計（税抜） | すべての医院の在庫の評価額を合計した金額です。税抜の金額です。 |
| ◯品目 | すべての医院に登録されている資材の延べ件数です。 |
| 在庫不足 ◯ | （現在庫＋未入荷）が発注基準以下になっている件数です。 |
| マイナス ◯ | 在庫が0より少なくなっている件数です。 |
| 期限間近 ◯件 | 使用期限が切れている、または1年以内に迫っている件数です。 |

### 医院ごとのカード

| 項目 | 説明 |
| --- | --- |
| 医院名（NIS／MDC／KDC／PV／訪問部） | 医院の記号です。 |
| ホームへ → | その医院の在庫管理ホームへ移動します。 |
| ￥◯ 資産額 | その医院の在庫の評価額です。 |
| ◯品目 | その医院に登録されている資材の件数です。 |
| ◯在庫不足 | その医院で在庫不足になっている件数です。 |
| 🔴 期限 ◯ | その医院で期限が近い・切れている件数です。 |
| 問題なし | 在庫不足・マイナス・期限のいずれも無い状態です。 |
| ← 理事長・事務ホームへ戻る | 「在庫管理ホーム（理事長・事務）」へ戻ります。 |

## 注意事項

- **表示までに時間がかかります。** 全医院分を集計するため、開いてから表示されるまで少し待ってください。
- **資産額は「税抜価格 × 現在庫」の合計です。** 商品マスタに税抜価格が登録されていない資材は0円として計算されるため、実際の金額より少なく出ることがあります。単価は「商品マスタ管理」画面で登録できます。
- **まだ棚卸しをしていない医院は￥0と表示されます。** 各医院が「一斉在庫登録」で実際に数えた数を入れると、そこから金額が出はじめます。
- **在庫の数を数えない資材（発注トリガー管理）は、資産額・在庫不足の集計に含まれません。**
- この画面では在庫の登録や修正はできません。操作は各医院のホームから行ってください。
- 「集計に失敗しました：◯◯」と表示されたときは、ページを再読み込みしてください。それでも直らない場合はシステム管理の担当者に連絡してください。

## よくある質問

**Q. 資産評価額が￥0になっています。**

A. 理由は2つあります。1つは、その医院がまだ棚卸しをしておらず在庫数が0のまま（数えた数を入れると金額が出ます）。もう1つは、商品マスタに「税抜価格」が登録されていない場合で、こちらは「商品マスタ管理」画面で単価を登録してください。

**Q. 「問題なし」と出ている医院は何もしなくてよいですか？**

A. その医院に在庫不足・マイナス在庫・期限が近い資材が無いという意味です。品目数が0の場合も「問題なし」と表示されるため、まだ資材が登録されていないだけの可能性もあります。

**Q. 医院ごとの詳しい在庫を見たいです。**

A. その医院のカードを押して在庫管理ホームへ移動し、「在庫一覧・検索」を開いてください。
