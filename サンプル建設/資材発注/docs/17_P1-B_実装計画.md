**対応不要（2026-07-09確定）**: `docs/16` D-20260709-01 により、現場間の直接移動は実装しないことが確定した。資材の流れは必ずセンター→現場→センター。本セクションは経緯として残す。

| | |
|---|---|
| **目的** | ~~現場 A→B（center 非経由）~~ → 対応不要 |
| **依存** | P1-B-1（B-2 と並行可） |
| **DB** | ~~`transfer_between_sites`~~ → 作成しない |
| **App** | ~~`/stock/transfers/new`~~ → 作成しない |
| **完了条件** | ~~A 減・B 増が同 TX。自社合計不変~~ |
| **分岐** | ~~U-5 で承認必須なら B-3a（記録のみ）/ B-3b（承認）に分割~~ → U-5 は解消（不要） |

**実施記録（2026-07-09）**: 「P1-B-3」という呼称は開発側の会話上で**返却履歴一覧ページ**（`/stock/returns`、下記 P1-B-4「履歴・整合性・監査」の一部に相当）へ転用し、実装・通常系テストを完了した。番号の再定義は行わず、本表は現場間移動が対応不要になった経緯としてのみ残す。
