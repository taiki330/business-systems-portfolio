# 資材移動（貸し借り）

![資材移動の画面](../images/transfer.png)

## この画面でできること

自分の医院の資材を他の医院へ渡したときに、在庫を移す画面です。渡した分だけ自分の医院の在庫が減り、渡した先の医院の在庫が増えます。

資材は画面の「📷 QRを撮影」から端末のカメラを開き、撮影したQR写真を読み取って選びます。

**移動元は、いま開いている医院で固定されています。** 「自分の医院から出す」ときだけ使う画面です。

## 操作手順

1. 医院ホームの「🔁 他院と貸し借り」を押します。
2. 「PV →」の右のプルダウンから、渡す相手の医院を選びます。
3. 必要であれば「担当者」に自分の名前を入れます（入れなくても登録できます）。
4. 「📷 QRを撮影」を押します。
5. 渡す資材のQRコード全体を、正面から撮影します。
6. 撮影した写真を使用します。
7. 「読取完了」と資材名、自分の医院の在庫数が表示されることを確認します。
8. 「－」「＋」または数字の入力で「移動数量」を決めます。
9. 「この内容で移動する」を押します。
10. 「◯◯を△△へ移動します。よろしいですか？」で「OK」を押します。
11. 「✓ 移動しました：◯◯」と表示されれば完了です。

## 各項目の説明

| 項目 | 説明 |
| --- | --- |
| PV（移動元） | 資材を出す側の医院です。画面を開いた医院で固定されており、変更できません。 |
| →（右のプルダウン） | 資材を渡す先の医院を選びます。自分の医院は選べません。 |
| 担当者：お名前（任意） | 移動を行った人の名前です。空欄のままでも登録できます。 |
| 📷 QRを撮影 | 端末のカメラを開いてQRコードを撮影します。端末内の画像を選ぶこともできます。 |
| QR撮影待ち／QR解析中…／読取完了／読取失敗 | QR写真の読み取り状態です。 |
| 移動数量（－ ／ ＋ ／ 数字） | 渡す数です。1以上の数を指定します。 |
| この内容で移動する | 選んだ資材・数量・移動先で在庫を移します。 |

## 注意事項

- **移動できるのは「数量管理」の資材だけです。** 在庫の数を数えない資材（発注トリガー管理）を読み取ると「数量管理の資材のみ移動できます（◯◯）」と表示されます。
- **移動先を選ばずに実行することはできません。** 「移動先の医院を選んでください。」と表示されます。
- **先に資材のQRを読み取ってください。** 読み取っていない状態で実行すると「先に資材のQRを読み取ってください。」と表示されます。
- **この画面では「借りる（他院から自分の医院へ入れる）」操作はできません。** 資材を出す側の医院で操作してください。
- 移動先の医院にその資材が登録されていない場合は、移動先に新しく作られます（「（移動先に新規作成）」と表示されます）。
- QR写真は端末内で解析し、システムには保存しません。
- 「QRコードを読み取れませんでした。QR全体を明るく、正面から大きく撮影してください。」と表示された場合は、QR全体が入るように撮影し直してください。

## よくある質問

**Q. 相手の医院から借りた資材を登録したいのですが。**

A. この画面は「自分の医院から出す」ための画面です。相手の医院の担当者に、相手の画面から移動してもらってください。

**Q. 「この医院に無い資材です（◯◯）」と表示されました。**

A. 読み取った資材が、自分の医院の在庫に登録されていません。医院が正しいか確認してください。登録が必要な場合は「商品マスタ管理」画面から追加できます。

**Q. 「このシステムのQRではありません。」と表示されます。**

A. このシステムで発行したQR以外を読み取っています。「QRコード生成」画面で印刷したQRを使ってください。

**Q. 「読取失敗」と表示されました。**

A. QRコード全体が入るように、明るい場所で正面から大きく撮影してください。

**Q. 移動する数を間違えました。**

A. 反対方向の移動を行うか、それぞれの医院で「訂正・取消」画面から在庫を修正してください。
